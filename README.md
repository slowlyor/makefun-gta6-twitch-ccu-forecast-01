A comparable-launch shape forecaster: it predicts GTA VI's hourly Twitch viewers from its hour-1 print using the median release-day shape of past rolling-midnight console launches.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
